An interrupt means the CPU gets a signal that needs its attention while it is already doing something else.

For example, when we press a key on the keyboard, the keyboard sends an interrupt to the CPU. 
The CPU temporarily stops its current work, handles the keyboard input, and then goes back to the work it was doing before.

The basic process is:
CPU is doing its normal work.
An interrupt comes.
CPU temporarily stops that work.
It handles the interrupt.
Then it continues the previous work.
