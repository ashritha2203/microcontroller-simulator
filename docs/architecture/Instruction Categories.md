Instructions are basically commands given to the CPU. 

Different instructions are used for different types of work.
The main categories are:

Data Transfer Instructions – Used to move data from one place to another.
Example: Moving data from memory to a register.

Arithmetic Instructions – Used for mathematical calculations.
Example: Addition, subtraction and multiplication.

Logical Instructions – Used to perform logical operations on data.
Example: AND, OR, NOT and XOR.

Control/Branch Instructions – Used when we need to change the normal order in which the program runs.
Example: Jump, Call and Return.

Input/Output Instructions – Used for communicating with input and output devices.
Example: Taking input from a keyboard.
