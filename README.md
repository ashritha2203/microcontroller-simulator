# microcontroller-simulator
Project Title
Educational Microcontroller Simulator with Process Scheduling

Problem Objective
The goal is to build a simple simulator that shows how a microcontroller runs programs, manages memory, and handles multiple programs at once. It  combines ideas from Microprocessor Architecture,Data Structures and Operating Sysytems into one working project, so we can see how a CPU actually runs code and decides which program gets to run next.
